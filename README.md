CNCLab — CNC Simulator

CNCLab is a CNC simulator developed in **C++17** using **Qt 6** for the graphical user interface and **CMake** as the build system.

The project aims to provide an interactive environment for CNC simulation, focusing on precision, usability, modularity, and extensibility.

## Technologies

- **C++17**
- **Qt 6 Widgets**
- **Qt 6 OpenGL Widgets**
- **CMake**

## Project Goals

- Develop an intuitive graphical interface.
- Simulate CNC machining operations.
- Implement a modular and maintainable architecture.
- Provide a foundation for future simulation features and improvements.

## Status

**Currently under development.**

## Building

The project uses CMake as its build system. Build instructions will be provided as development progresses.
